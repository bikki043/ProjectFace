# Custom scan sounds

ใส่ไฟล์เสียงของคุณเองในโฟลเดอร์นี้ด้วยชื่อไฟล์:

- `check-in.mp3` เสียงเช็คอินสำเร็จ
- `check-out.mp3` เสียงเช็คเอาท์สำเร็จ
- `error.mp3` เสียงสแกนไม่ผ่านหรือเกิดข้อผิดพลาด

รองรับไฟล์เสียงที่ browser เล่นได้ เช่น `.mp3`, `.wav` และ `.ogg`
ถ้าไม่มีไฟล์หรือไฟล์เล่นไม่ได้ ระบบจะใช้เสียง beep สำรองอัตโนมัติ
